# Items Limiter

Control your server's economy and progression by setting **global limits** on items and enchantments.

**Items Limiter** lets server administrators define exactly how many copies of an item may exist across the entire server. Whether you want only **one Mace in the world**, allow **five Elytras**, or ban Totems entirely, the mod automatically enforces your rules.

You can also limit enchantments by their maximum level or disable them completely.

Perfect for SMPs, PvP servers, hardcore worlds, and custom progression packs.

## Features

### 🌍 Global Item Limits

Set a server-wide maximum for any item.

Examples:

* Only **1 Mace** may exist on the server.
* Allow a maximum of **5 Elytras** globally.
* Ban **Totems of Undying** by setting the limit to **0**.

### ✨ Enchantment Limits

Restrict enchantments to a maximum level.

Examples:

* Protection → maximum level **III**
* Sharpness → maximum level **IV**
* Disable Mending entirely by setting its maximum level to **0**

### 🔧 In-Game Administration

Configure everything without restarting the server.

Commands allow you to:

* Set or remove item limits
* Set or remove enchantment limits
* View all configured limits
* Reload the configuration
* Scan players and the world to enforce configured limits
* Reset an item's registry when needed
